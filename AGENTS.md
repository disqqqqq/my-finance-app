# AGENTS.md — правила работы над личным приложением учёта финансов

## О пользователе
- Пользователь не программирует и не хочет писать код вручную.
- Работает с iPad и iPhone, Mac нет.
- Все технические задачи ИИ выполняет самостоятельно.
- Объяснения — простым языком, без лишних терминов.
- Платные сервисы и облачные хранилища подключать только после явного согласия.
- Нельзя утверждать, что функция работает, без реальной проверки доступными средствами.

## Проект
Личное приложение для учёта доходов и расходов на iPhone.

### Текущий подход
- Веб-приложение (PWA), оптимизированное для Safari на iPhone.
- Можно добавить на главный экран как иконку.
- Данные хранятся локально в браузере (localStorage), с экспортом/импортом резервной копии и CSV.
- Курс USDT/RUB берётся из публичного источника; при недоступности курс не выдумывается.
- Голосовой ввод на русском через Web Speech API, с ручным вводом как обязательной альтернативой.

### Файлы
- `index.html` — всё приложение: интерфейс, логика, хранение данных.
- `manifest.webmanifest` — настройки иконки и режима приложения.
- `sw.js` — офлайн-кэш.
- `icon.svg` — иконка приложения.

## Порядок работы в каждом новом чате
1. Прочитать этот файл.
2. Проверить текущие файлы проекта.
3. Продолжить с последнего этапа, не переделывая готовое без необходимости.
4. После этапа кратко сообщить: что готово, что проверено, что делать пользователю дальше.

## Этапы
1. Способ разработки, доступный с iPad.
2. Минимальная рабочая версия.
3. Операции, категории, статистика.
4. Голосовой ввод и USDT.
5. Проверка интерфейса iPhone и исправления.
6. Сохранность данных и резервное копирование.
7. Публикация и добавление на главный экран.

## Важные правила данных
- Не терять финансовую историю.
- Перед удалением операции запрашивать подтверждение.
- Сохранять исходную сумму, валюту, использованный курс и время курса.
- Не публиковать финансовые данные и секреты в коде.
